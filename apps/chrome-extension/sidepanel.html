📥 Import Tab — How It Works

A

Prepare Your CSV / Excel File

Your file must have these column headers: name, phone, email, website, address, whatsapp. Column names must be exact (lowercase). Phone numbers should include country code (e.g. +8801XXXXXXXXX). Save as .csv or .xlsx.

B

Upload & Import Your Leads

Go to the Import tab → click Choose File → select your CSV/Excel → click Import Leads. Your leads will appear in the list below. The total count is shown at the top.

C

Send WhatsApp SMS to Imported Leads

Make sure WhatsApp is connected (WhatsApp tab → scan QR). Then go to Import tab → write your message template → click Send WhatsApp. Sending runs in the background — you can close the popup. Progress is shown live.

D

Send Email to Imported Leads

Connect Gmail first (Email tab). Then go to Import tab → write Subject & Body → click Send Email. Supports Bangla, Arabic, Hindi in the subject line — all languages work correctly.

E

Send Both WhatsApp + Email Together

Go to Import tab → fill WhatsApp message + Email subject & body → click Send Both. The extension sends WhatsApp first, then Email, for each lead automatically. Both run in the background.

F

Stop & Resume Sending

Click Stop anytime to pause. The extension remembers where it stopped. Click Resume to continue from the same lead — no leads are skipped or re-sent.

🔒 Duplicate Filter — How It Works

1

Automatic Duplicate Protection

LeadOutfy automatically tracks every lead collected and every WhatsApp SMS / Email sent. If the same phone number or email address appears again — it is automatically skipped. This protects your sender reputation and avoids annoying clients.

2

Hunt Duplicate Filter

When scraping Google Maps, if a business phone number was already collected in a previous session — it will be skipped automatically. You will see "Already hunted — skip" in the status bar. This works across all sessions permanently.

3

WhatsApp SMS Duplicate Filter

If a phone number already received a WhatsApp SMS (in Hunt mode, Import Single, or Import Both) — the same number will be skipped next time. The log will show "Already sent — skipped". Works across all sending modes.

4

Email Duplicate Filter

If an email address already received an email (in Hunt mode, Import Email, or Import Both) — the same address will be skipped automatically. The log shows "Already sent — skipped". Prevents Gmail spam flags and protects your sender score.

5

History is Permanent — Until You Reset

The duplicate history is saved permanently in your browser. It survives PC restarts, browser updates, and extension updates. It only clears when you click a Reset button. Stores up to 500,000 phone numbers and 500,000 email addresses.

🔄 Reset Buttons — What They Do

R1

🔄 Hunt Reset

Clears the list of phone numbers that were previously collected from Google Maps. After clicking this, the extension can collect the same businesses again in future scraping sessions. Use this if you want to re-scrape an area you already scraped before.

R2

🔄 WA SMS Reset

Clears the list of phone numbers that already received a WhatsApp SMS. After clicking this, the same phone numbers can receive WhatsApp messages again. Use this when running a new promotion campaign to the same contacts.

R3

🔄 Email Reset

Clears the list of email addresses that already received an email. After clicking this, the same email addresses can receive emails again. Use this for follow-up campaigns or new promotional emails to existing contacts.

⚠️ Important: Results Clear vs Reset History

• 🗑 Clear button (top of Dashboard) → only clears the lead list on screen. History is NOT affected.
• 🔄 Reset buttons → permanently clears the duplicate history. Use only when you want to re-send to old contacts.
• Resetting history does NOT delete your leads — it only allows the same numbers/emails to be contacted again.
